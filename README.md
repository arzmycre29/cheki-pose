# 📷 ChekiPose - Chika Idol Pose Helper & Generator 💖

Webapp pembantu dan penentu pose foto **Cheki (2-shot polaroid)** bersama idol favoritmu. Dirancang khusus untuk para penggemar Chika Idol, JKT48, Underground Idol, dan event jejepangan agar tidak lagi merasa bingung atau "blank" saat giliran cheki tiba!

🌐 **Akses Online Langsung (GitHub Pages):**  
👉 **[https://arzmycre29.github.io/cheki-pose/](https://arzmycre29.github.io/cheki-pose/)**

---

## ✨ Fitur Utama

### 1. 🎀 Tiga Mode Utama Pose
- **🎀 Cute Mode (Default):** Pose manis, kawaii, sweet couple, dan klasik idol (*Half Heart, Nyan Cat Paws, Pipi Bakpao, Usagi Ears, Chin Flower*).
- **✨ Fun Mode (Unik & Interaktif):** Pose interaktif, adu gaya, mini-roleplay, dan duel seru (*VIP Idol & Bodyguard, Panco Seru, Janji Kelingking, Tos Melayang, Detective & Suspect*).
- **🎭 Random Meme (Kocak & Chaos):** Pose absurd dari meme internet, anime, dan kekacauan wota (*JoJo Menacing, Kamehameha Beam, Nangis Terharu di Depan Oshi, Dompet Kering, Spider-Man Pointing*).

### 2. 🎲 Gacha / Roulette Pose
- Putar gacha dalam 3 detik untuk mendapatkan inspirasi pose spontan saat antrean cheki hampir tiba.
- Dilengkapi efek suara sintetis (*Web Audio API*) tanpa perlu unduh file MP3 besar.

### 3. 📱 Mode "Tunjukkan ke Oshi" (Show-to-Idol)
- Layar penuh berlatar gelap kontras tinggi dengan tipografi raksasa dan ilustrasi diagram posisi tangan (Fan vs Idol).
- Mengatasi kebisingan audio venue konser dan sekat akrilik pembatas bilik cheki tanpa perlu berteriak.
- Dilengkapi *Screen Wake Lock API* agar layar HP tidak mati otomatis saat mengantre.

### 4. 🎫 Rencana Tiket & Wishlist Hari Ini
- Susun antrean pose per tiket cheki (Tiket #1, Tiket #2, dst.).
- Centang tiket yang sudah selesai dieksekusi secara real-time.
- Tersimpan 100% aman dan privat di browser (`localStorage`).

### 5. 📸 Instax Mini Studio
- Preview pose di dalam simulasi frame film polaroid Instax Mini klasik.
- Kustomisasi tulisan spidol: Nama Oshi, Tanggal Event, dan Pesan Singkat.
- Unduh hasil kartu kenangan dalam format gambar `.png` resolusi tinggi.

### 6. 🖼️ Dukungan Foto Referensi Pribadi & Pencarian Live
- Unggah foto referensi cheki favoritmu sendiri ke pose mana pun.
- Tautan pencarian langsung ke Twitter/X hashtag `#チェキポーズ` untuk melihat tren pose idol terbaru.

---

## 🛠️ Teknologi & Arsitektur

- **100% Client-Side:** HTML5 Semantic, Modern Vanilla CSS, dan ES Modules.
- **PWA Ready:** Dilengkapi Web App Manifest, dapat ditambahkan ke Home Screen smartphone (*Add to Home Screen*).
- **Vector Silhouette Diagrams:** Ilustrasi SVG ringan, jernih di semua resolusi layar retina/smartphone, dan hemat kuota internet.
- **Deployment:** Otomatis melalui GitHub Pages & GitHub Actions.

---

## 📱 Cara Penggunaan di Smartphone

1. Buka link **[https://arzmycre29.github.io/cheki-pose/](https://arzmycre29.github.io/cheki-pose/)** di browser HP (Chrome / Safari).
2. (Opsional) Pilih menu browser lalu klik **"Add to Home Screen" / "Tambahkan ke Layar Utama"** untuk menjadikan aplikasi seperti native app.
3. Pilih mode (*Cute, Fun, Meme*), putar gacha atau cari di katalog, lalu klik **"📱 Tunjukkan ke Oshi"** saat giliranmu masuk bilik cheki!
